# Smart Building Control — Aalborg University BUILD

!!! abstract "Project Collaboration"
    This project is developed in collaboration with the **Department of Civil Engineering (BUILD)** at **Aalborg University (AAU)**.
    It investigates how intelligent, coordinated control algorithms can improve the performance of highly automated buildings.

---

## About the BUILD Facility

The BUILD building is equipped with a dense network of sensors (light, temperature, CO₂, occupancy) and supports automated control of blinds, heating, and ventilation.  
Despite the high degree of automation, existing controllers work independently and face challenges due to weather conditions, heat generation, and system interactions.

The facility provides open interfaces for developing and testing **advanced control algorithms** in a real-world environment.
