## How to Create These Issues

To create these issues in GitHub:

1. Navigate to the repository's Issues page
2. Click "New Issue"
3. Select the "Task template" if available
4. Copy the content from each section above
5. Set the appropriate labels, assignees, and milestone
6. Link to parent issue #47 in the "relationship for the issue" section
7. Create the issue

Alternatively, if you have GitHub CLI (`gh`) installed and configured:

```bash
# Example for G 5.5
gh issue create \
  --title "G 5.5 | Optimise the runtime of PySINDy" \
  --body-file <(cat <<EOF
## Task description
Analyze and optimize the runtime performance of PySINDy model training and inference...
EOF
) \
  --label "enhancement" \
  --assignee "toita86,beltranaceves" \
  --milestone "M1_Modeling"
```
