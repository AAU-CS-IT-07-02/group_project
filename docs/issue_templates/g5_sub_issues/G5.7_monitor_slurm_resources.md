## Task description

Implement a monitoring solution for tracking resource usage (CPU, memory, time) during SLURM experiments. This will help optimize resource allocation, detect issues early, and ensure efficient use of computational resources.

The monitoring system should provide:
- Real-time or near-real-time resource usage data
- Historical resource usage for completed jobs
- Alerts for jobs exceeding resource limits
- Resource usage visualization
- Recommendations for optimal resource allocation

## Expected outcome

- Resource monitoring scripts integrated with SLURM jobs
- Real-time or post-execution resource usage reports
- Documentation on how to interpret monitoring data
- Guidelines for optimal resource allocation based on monitoring results
- Automated alerts for jobs exceeding resource limits or failing

## Documentation

### Tools and Approaches to Investigate

1. **SLURM Built-in Commands**
   - `sstat`: Real-time job statistics
   - `sacct`: Historical accounting data
   - `squeue`: Job queue status with resource usage
   - `scontrol show job <jobid>`: Detailed job information

2. **Custom Monitoring Scripts**
   - Python script using `psutil` for detailed metrics
   - Periodic sampling of resource usage
   - Log resource usage to timestamped files

3. **Integration with Existing SLURM Scripts**
   - Modify SLURM job templates to include monitoring
   - Add monitoring calls at key points in job execution
   - Capture resource usage before and after main computation

4. **Log Parsing and Analysis**
   - Parse SLURM output files for resource usage
   - Aggregate resource usage across multiple jobs
   - Generate summary statistics and visualizations

### Example Monitoring Script Structure

```bash
#!/bin/bash
# In SLURM job script

# Start monitoring in background
python monitor_resources.py ${SLURM_JOB_ID} &
MONITOR_PID=$!

# Run main computation
python pysindy_experiment.py

# Stop monitoring
kill $MONITOR_PID

# Generate resource usage report
python analyze_resources.py ${SLURM_JOB_ID}
```

### Metrics to Monitor

- **CPU Usage**: Percentage utilization, number of cores used
- **Memory Usage**: Current usage, peak usage, swap usage
- **Time**: Wall-clock time, CPU time
- **I/O**: Read/write operations, data transfer
- **GPU Usage**: If applicable
