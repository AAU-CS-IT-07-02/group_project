## Documentation

### Key Hyperparameters to Document

1. **Feature Library Parameters**
   - Polynomial degree: [1, 2, 3, 4, 5]
   - Include interaction terms: [True, False]
   - Custom library functions to test

2. **Optimizer Parameters**
   - Threshold (sparsity): [0.001, 0.01, 0.05, 0.1, 0.5]
   - Alpha (regularization): [0.001, 0.01, 0.1, 1.0]
   - Max iterations: [100, 500, 1000]
   - Optimizer type: [STLSQ, SR3, SSR]

3. **Differentiation Method Parameters**
   - Method: [finite_difference, spectral, spline, trend_filtered]
   - Smoothing parameter ranges
   - Window size for finite difference

4. **Model Structure Parameters**
   - Feature library composition
   - Ensemble size (if using ensemble methods)

5. **Training Parameters**
   - Train/test split ratio: [0.7, 0.8, 0.9]
   - Cross-validation folds: [3, 5, 10]

### Configuration File Format

Create a YAML configuration structure:
```yaml
experiment:
  name: "pysindy_experiment_001"
  dataset: "path/to/dataset.csv"
  
hyperparameters:
  feature_library:
    polynomial_degree: [2, 3, 4]
    include_interaction: true
  
  optimizer:
    type: "STLSQ"
    threshold: [0.01, 0.05, 0.1]
    alpha: [0.001, 0.01]
    max_iter: 1000
  
  differentiation:
    method: "finite_difference"
    order: 2
```
