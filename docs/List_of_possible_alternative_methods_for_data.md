**List of possible alternative methods**

Here is the list of possible alternative methods (these complement MPC):

-   A lumped RC thermal model (simplified representation of thermal system) could be used for basic thermodynamics. Key libraries for this are numpy, scipy, matplotlib;
-   Grey-box parameter estimation could be used to fit physical parameters to data and we could use scipy.optimize and pandas
-   Reduced-order modeling to simplify complex systems, using numpy, scipy.linalg, control
-   Subspace ID (N4SID/MOESP) fro linear state-space from data, using sippy, control
